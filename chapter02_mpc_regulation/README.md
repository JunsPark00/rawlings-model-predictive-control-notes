## 원본 사례의 재현 범위와 수치 불일치

- **Examples 2.5–2.6, pp.99–104:** 원본 모델 `x⁺=x+u`, `N=2`, 입력 한계 ±1과 비용의 1/2를 유지합니다. 입력 열의 구간별 해석식, 상태를 제거한 QP, 상태·입력 동시 QP를 대조하고 비용 등고선과 제약 최적점을 그립니다.
- **원본 p.100의 수치 불일치:** 원본은 초기상태 10의 최적 비용을 124로 표기합니다. 제시된 상태 `10,9,8`과 입력 `−1,−1`을 비용식에 대입하면 `(100+81+64+1+1)/2=123.5`입니다. 본 자료는 불일치를 명시하고 **직접 계산값 123.5**를 검증 기준으로 사용합니다.
- **Example 2.8, pp.105–107:** 원본 비선형 모델과 종단 원점 조건으로 첫 입력의 실행 가능 영역을 계산하고 후속 입력을 복원합니다. 원본의 불연속 최적 제어법·값 함수 그림 전체나 전역 최적해를 재현한 실험은 아닙니다. 분모가 0인 특이 경우도 설명합니다.
- 나머지는 직접 설계한 **보충 실습**입니다. 특히 다변수 종단 다각형은 자체 이중 적분기 모델에 대한 결과입니다. 원본의 모든 사례·증명·연습문제 해답을 수록하지 않습니다.
- 제어 이득은 `u=Kx` 관례로 K에 음의 부호를 포함합니다. 원본 재현 외 보충 LQ 실습은 비용의 공통 계수 1/2를 생략하고, 값 함수 감소 검사에도 같은 정의를 사용합니다.

## 코드와 해석에서 개선한 점

- 스칼라 종단 반경의 정확한 한계 `min(xmax, umax/|K|)`를 유도하고 경계점에서 인증합니다. 반경을 1.5배로 키운 N=1 QP 반례에서 비용 감소 항등식이 유지되어도 이동 후보 입력이 한계를 0.5만큼 넘는 것을 확인합니다. 다음 QP 재최적화는 가능하므로 후보 증명 실패와 MPC 전체 실패를 구분합니다. `demo_terminal_radius(enlargement=1.2)`에서는 위반량 0.2를 확인하며, 배율과 상태 한계를 입력 검증으로 확인합니다.

- QP 공통 함수가 솔버 상태와 실제 등식·부등식 잔차를 함께 검사합니다. 실행 불가능 상태는 요청한 경우에만 `None`으로 반환하며 이전 해를 재사용하지 않습니다.
- 예측 길이·비용 가중치·제약 상한·초기상태를 확인하고, 반복 스칼라 MPC는 초기상태 Parameter로 문제를 재사용합니다.
- 새 실습은 독립적인 설정을 가지며 주요 계산 결과를 반환합니다. 공통 준비 코드 두 셀 이후 개별 실행할 수 있습니다. 코드 형식을 정리하고 고정 난수를 유지했습니다.
- 종단 다각형은 모든 꼭짓점에서 한 단계 변화를 검사합니다. 선형 제약의 볼록 집합 검증이며 단순한 상태 격자 테스트와 구분합니다. 계산한 것은 **고정 K의 최대 허용 불변 집합**이지 임의 입력에 대한 최대 제어 불변 집합이 아닙니다.
- 외란으로 이동 후보가 깨지는 것과 다음 MPC 문제 전체가 불가능한 것을 구분합니다. 보충 사례에서는 이동 후보가 실패해도 재최적화는 가능합니다.
- 출력 비용 감소, 지수 감쇠 상한, 주기 위상, 경제적 평균 성능의 가정을 그래프 해석에 명시합니다. 비선형 SLSQP의 실행 가능한 국소해를 전역 최적해라고 부르지 않습니다.

## 실행과 재생성

Colab에서 `런타임 → 모두 실행`을 선택하세요. 개별 실습은 공통 준비 코드 **두 셀**을 먼저 실행합니다. 1장 실행이나 저장소 복제가 필요 없고 CPU만 사용합니다. 필요한 패키지·나눔고딕 글꼴 다운로드에는 최초 인터넷 연결이 필요합니다. 그래프는 현재 작업 폴더 `figures/`에 저장됩니다.

```bash
python -m pip install -r requirements-colab.txt nbformat nbclient ipykernel
python tools/check_notebooks.py chapter02_mpc_regulation/examples/chapter02.ipynb
```

실행 결과와 그림을 기존 챕터에 저장하고 PPT를 재생성하려면:

```bash

python -m pip install "python-pptx>=1.0,<2" "Pillow>=11,<13"
python tools/build_chapter02_slides.py
```

PPT의 본문·도형·수식은 편집 가능하며 그래프는 이미지입니다. 재생성은 기존 PPT를 덮어쓰므로 편집한 설명을 `tools/chapter02_slide_content.json`에도 반영하세요. 생성기의 기본 글꼴 측정 경로는 WSL의 `/mnt/c/Windows/Fonts/malgun.ttf`, `malgunbd.ttf`입니다. 다른 환경에서는 `MPC_SLIDE_FONT`, `MPC_SLIDE_FONT_BOLD`로 한글 글꼴 파일 경로를 지정합니다. PowerPoint 표시 글꼴은 맑은 고딕·Cambria Math입니다.
