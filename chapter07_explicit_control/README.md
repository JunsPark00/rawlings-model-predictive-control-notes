## 모델과 해석

- 원본 예제 7.11·7.12의 문제와 임계 영역을 재현합니다. 다른 수치 사례는 **직접 설계한 보충 실습**입니다. 교재의 모든 예제·증명·연습문제 해답을 재현하지 않습니다.
- 주 QP는 2상태·1입력·예측 구간 2, `A=[[0.8,0.2],[0,0.7]]`, `B=[0.2,0.5]ᵀ`, `Q=I`, `R=0.3`을 사용합니다. 입력 한계는 0.7, 상태 한계는 `[2.5,1.5]`, 종단 상자는 각 성분 ±1입니다. 종단 비용은 영 입력의 리아푸노프 등식으로 구합니다.
- 독립 활성 집합 **79개**를 검사해 내부가 있는 임계 영역 **9개**를 얻습니다. 반평면 교차로 영역을 계산하며 격자 회귀로 제어법칙을 근사하지 않습니다. 같은 첫 입력 식의 영역을 최소 개수로 병합하지 않았습니다.
- 온라인 비교 QP는 원래 상태·입력 변수와 동역학으로 따로 구성합니다. 상태 제거 행렬의 오류를 함께 검출할 수 있습니다. 표본 검증은 수학적 증명과 구분합니다.
- 스칼라 DP는 `x⁺=0.9x+u`, 입력 ±0.4, 상태 ±2, 종단 상태 ±0.6, 단계 비용 `(x²+0.2u²)/2`를 사용합니다. 각 이차 조각의 내부·경계 후보와 비용 교점으로 하단 포락선을 계산합니다. 부동소수점 허용오차를 사용하는 교육용 1차원 구현입니다.
- LP 실습은 비유일한 최적 선분, 유일한 구간별 아핀 해, 절댓값 비용의 MPC를 서로 다른 문제로 구분합니다. 솔버의 한 반환값을 유일성의 증거로 해석하지 않습니다.
- 영역 밖 입력 요청은 오류로 반환합니다. 제어법칙의 배포나 실제 장치의 계산 성능을 검증하는 자료는 아닙니다.
