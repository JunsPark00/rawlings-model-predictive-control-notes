## 원본 재현과 보충 실습의 범위

- §1.3.4의 유한 구간 불안정 사례는 **교재 pp.21–22의 행렬·가중치**를 사용합니다.
- Example 1.11은 **교재 pp.53–59에 인쇄된 반올림 선형 행렬**로 확장 모델의 계수와 관측 불가능한 방향을 검사합니다. 원본의 비선형 반응기 응답 Figures 1.8–1.11를 재현한 것은 아닙니다.
- 열 확산·제약 설계·스칼라 추종 등은 **직접 설계한 보충 실습**입니다. 원본의 입자 성장 모델이나 모든 사례의 재현을 주장하지 않습니다.
- 원본의 주요 개념을 한국어로 재서술합니다. 모든 증명·연습문제의 해답집은 아닙니다. §1.6에서 Exercises 1.5, 1.8, 1.22를 안내합니다.
- `u = Kx` 관례로 K에 음의 부호를 포함합니다. 제어 비용 `Q,R`과 잡음 공분산 `W,V`를 구분합니다.
- MHE의 `window`는 측정 개수입니다. 측정 8개에는 전이 입력 7개를 사용하고, 구간 시작 측정은 도착 비용과 중복 계산하지 않습니다.
- Gaussian 그림의 2차원 Mahalanobis 반지름 2 타원은 약 86.5% 영역입니다. KF 그림의 **각 성분** ±2 표준편차와 구분합니다.
- 잡음이 지속되면 순간 추정 오차가 0이 된다고 보장하지 않습니다. 무오프셋 추종도 목표 실행 가능성·확장 검출 가능성·정상상태 도달 등 원본의 가정이 필요합니다.

## 코드에서 개선한 점

- 최소제곱과 MHE에서 공분산 역행렬을 직접 만드는 대신 **Cholesky 백색화 + `lstsq`**를 사용합니다. 수치적으로 불리한 정규방정식을 직접 풀지 않습니다.
- KF는 측정 전/후 시점을 명시하고, 마지막에 불필요한 상태 예측을 하지 않습니다. Joseph 공분산 갱신과 대칭화를 사용합니다.
- QP는 최적 상태뿐 아니라 실제 등식·부등식 잔차를 검사합니다. 반복 MPC는 초기상태 Parameter로 같은 문제를 재사용합니다.
- 구간 길이·입력 형식·추정의 유일성을 확인하고, 같은 초기정보·데이터·평가 시점으로 결과를 비교합니다.
- 새 실습은 설정을 함수 안에서 정의하고 주요 계산 결과를 반환합니다. 앞 실습에서 생긴 변수에 의존하지 않으므로 공통 준비 셀 이후 개별 실행할 수 있습니다.

## 실행과 자료 재생성

Colab에서 `런타임 → 모두 실행`을 선택하세요. 개별 실습은 공통 환경 준비 셀을 먼저 실행합니다. CPU만 사용하며 노트북이 필요한 패키지와 한글 글꼴을 준비합니다. 최초 실행에는 인터넷 연결이 필요합니다. 그림은 현재 작업 폴더 `figures/`에 저장됩니다.

로컬 검증은 저장소 루트에서 실행합니다:

```bash
python -m pip install -r requirements-colab.txt nbformat nbclient ipykernel
python tools/check_notebooks.py chapter01_getting_started/examples/chapter01.ipynb
```

실행 결과와 그림을 기존 챕터 폴더에 갱신하려면 `--write`를 붙입니다. PPT는 편집 원본이며, 코드로 재생성할 때는 기존 편집 내용을 덮어쓰므로 **`tools/chapter01_slide_content.json`에도 변경을 반영**하세요.

```bash
python tools/check_notebooks.py --write chapter01_getting_started/examples/chapter01.ipynb
python -m pip install "python-pptx>=1.0,<2" "Pillow>=11,<13"
python tools/build_chapter01_slides.py
```

생성기의 기본 글꼴 측정 경로는 WSL의 `/mnt/c/Windows/Fonts/malgun.ttf`, `malgunbd.ttf`입니다. 다른 환경은 `MPC_SLIDE_FONT`, `MPC_SLIDE_FONT_BOLD` 환경변수로 한글 글꼴 파일 경로를 지정하세요. PowerPoint의 실제 표시 글꼴은 맑은 고딕·Cambria Math입니다.

Windows PowerPoint가 설치된 환경에서 PPT를 PDF로 내보냅니다:

```powershell
powershell -ExecutionPolicy Bypass -File tools/export_pdf.ps1 -Pptx chapter01_getting_started/slides/chapter01_slides.pptx
```
