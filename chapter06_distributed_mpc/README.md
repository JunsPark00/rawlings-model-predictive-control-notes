**원본 예제 6.9의 해석:** `unstable Nash equilibrium`은 해당 최선 반응 반복이 내시점으로 수렴하지 않는다는 의미로 구분합니다. 국소 최적성 연립식에는 해가 존재하며, 이를 직접 풀어 적용한 가상 폐루프의 반지름은 0.882853입니다. 이 수치를 발산하는 분산 반복의 실제 제어 성능으로 읽으면 안 됩니다. 원본에 제시된 반복 반지름 1.11은 재현됩니다. 예제 6.10은 반복이 수렴해도 폐루프가 불안정한 별개의 반례입니다.

**예제 6.22의 범위:** 원본 다항식 동역학, 초기 상태 (3,−3), Q=R=I, 입력 범위 [−2.5,2.5], 원점 DARE 종단 비용을 사용합니다. Figure 6.10에 연결한 초기 N=1 비용 분석이며 시작 입력은 이번 실습에서 (0,0)으로 정했습니다. Figure 6.9의 N=2 폐루프와 종단 영역은 재현하지 않습니다. 앞의 수축 모델에 사용한 영 입력 종단 조건을 원본의 불안정 모델에 적용하지 않습니다.

코드는 비용 행렬의 차원·유한성·대칭성·정부호 조건, 참여자 블록의 중복·누락, 투영 시작점과 기울기를 검사합니다. QP는 솔버 상태·유한 목적값·제약 잔차를 확인합니다. 잘못된 설정 16건, N=1의 비용 인덱스, 입력 경계에서의 비용 감소를 별도로 검증했고, 코드 셀을 읽기 쉬운 여러 줄 형식으로 정리했습니다.

## 실습의 가정과 해석

- 예제 6.9–6.12의 원본 모델·설정·반복 고유값을 재현하고, 예제 6.22의 초기 N=1 비용을 분석합니다. 그 밖에는 직접 설계한 **보충 실습**입니다. 전체 수치 예제·증명·연습문제 해답을 재현하지 않습니다.
- §6.5.1–6.5.2는 교재 그림 6.7–6.8의 목적함수에 상수 2를 더합니다. 입력 범위는 `[0.1,4]`이며 시작점과 종료 조건을 코드에 명시합니다. 상수 이동은 최적점과 비용 차이를 바꾸지 않습니다.
- 실제 시간 `k`, 같은 시간 안의 반복 `p`, 예측 구간 `N`을 구분합니다. `U`는 전체 예측 입력 열이고 각 참여자는 자기 입력 열만 변경합니다.
- LQ 해법 비교·독립 입력 제약·외란 보상 실습은 `A=diag(0.75,0.65)`, `B=[[1,0.4],[0.3,1]]`, `Q=I`, `R=0.2I`, 구간 6을 사용합니다. 종단 비용은 안정한 계의 영 입력 무한 구간 비용입니다.
- §6.1.2의 유한 반복 실습은 입력 상자 투영 기울기 1회와 끝 입력 0으로 이동한 시작점을 사용합니다. 입력 열이 제어기의 내부 기억임을 구분하며, 현재 상태만의 균일 리아푸노프 안정성을 비용 감소 하나로 주장하지 않습니다.
- §6.2의 제어 방식 비교는 `A=0.75I`, 입력 결합 1.8, 국소 입력 가중치 0.1인 한 단계 게임입니다. 분권 폐루프 고유값, 비협조 반복 고유값, 내시점 존재, 중앙집중 비용은 별개로 검사합니다.
- 협조 갱신은 같은 이전 입력 열에서 만든 **전체 후보 벡터들의 가중 평균**입니다. 각자의 새 입력을 그대로 붙이는 연산과 다릅니다.
- 독립 입력 제약 실습은 고정 상태에서 QP 반복의 실행 가능성과 최적해 일치를 확인합니다. 불안정 계의 종단 모드 제거·원점 근처 입력 열 제한 등 교재 정리의 모든 안정성 제약을 구현하지 않습니다.
- 독립 상자 QP의 추가 종료 실습은 볼록 접평면과 강볼록 하한으로 계산한 목적값 오차 인증값을 비교합니다. 중앙집중 해는 사후 검증에만 사용하며 인증 상한 1e-6에서 종료합니다. 활성 제약의 최적해는 원래 기울기가 0이 아닐 수 있어 투영 잔차를 함께 봅니다. 정확한 전체 기울기·곡률 정보가 필요하며 폐루프 안정성이나 통신 지연의 보장은 아닙니다.
- 공유 자원 예는 `u1,u2≥0`, `u1+u2≤1`인 삼각형입니다. 블록별 개선이 멈춘 경계점과 전체 최적점을 비교하여, 실행 가능성과 비용 감소가 전체 최적성을 뜻하지 않음을 확인합니다.
- 상태 추정은 잡음 없는 예측형 관측기입니다. 현재 입력을 계산한 뒤 현재 측정으로 다음 추정을 갱신하고, 다른 참여자의 실제 적용 입력도 반영합니다.
- 외란 보상은 무제약·상수 외란의 보충 실습입니다. 국소 확장 관측기로 외란을 추정하고 목표 평형은 전체 선형 등식으로 풉니다. 동적 입력 열은 시간당 협조 반복 3회로 계산합니다. 제약·잡음이 있는 경우의 일반 보장을 주장하지 않습니다.
- 비볼록 알고리즘은 투영 기울기, Armijo 후퇴 탐색, 가중 후보 비용 검사와 후보 제외를 구현합니다. 종료 시 투영 기울기 잔차를 확인하며 전역 최적점이 아닌 정상점으로 해석합니다.
- 비선형 MPC는 `x⁺=0.7x+0.08tanh(swap(x))+u`, `|u_i|≤0.6`, 구간 5를 사용합니다. 상태 강제약은 없습니다. 영 입력의 전역 수축률 0.78로 종단 비용 계수를 정하고, 시간당 1회·4회 개선을 비교합니다. 비용 기울기는 예측 경로를 통해 역전파하며 유한차분과 대조합니다.
- 비선형 제어의 시간 간 감소는 이동 시작점과 분산 개선의 두 부등식을 결합합니다. 수치 경로 확인과 일반적인 안정성 정리의 증명은 구분합니다.

## 편집과 PDF 갱신

`slides/chapter06_slides.pptx`가 편집 원본입니다. 본문·도형·수식 표기는 편집 가능한 PowerPoint 요소이고, 실습 그래프는 이미지입니다.
수식은 글꼴과 위·아래 첨자를 적용한 텍스트입니다. PDF는 Windows PowerPoint에서 직접 내보냅니다.
노트북 그림과 검토한 설명 JSON으로 PPT를 재생성합니다. 저장소 루트에서:

```bash
python -m pip install python-pptx Pillow nbformat nbclient ipykernel
python tools/check_notebooks.py --write chapter06_distributed_mpc/examples/chapter06.ipynb
python tools/build_chapter06_slides.py
```

빌더는 `tools/chapter06_slide_content.json`과 기존 `slides/*.png`를 사용합니다. 기본 글꼴은 WSL에서 접근하는 Windows 맑은 고딕이며 `MPC_SLIDE_FONT`, `MPC_SLIDE_FONT_BOLD`로 경로를 지정할 수 있습니다. 빌더는 PPT를 덮어쓰므로 수동 수정 내용은 설명 JSON과 빌더에도 반영하세요.

PDF 변환:

```powershell
powershell -ExecutionPolicy Bypass -File tools/export_pdf.ps1 -Pptx chapter06_distributed_mpc/slides/chapter06_slides.pptx
```

노트북 파라미터를 바꾸면 그림을 다시 생성하고 PPT의 해당 그림·설명·수치도 갱신한 뒤 PDF를 내보내세요.
노트북 수정만으로 PPT·PDF가 자동 갱신되지는 않습니다.

전체 챕터 노트북을 임시 폴더에서 검증하려면:

```bash
python -m pip install -r requirements-colab.txt nbformat nbclient ipykernel
python -m ipykernel install --sys-prefix --name python3
python tools/check_notebooks.py
```
