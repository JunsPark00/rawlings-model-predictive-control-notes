## 실습의 정보 조건과 해석

- Example 4.40은 원본 식의 수치 적용, Example 4.41은 원본 명목 반응기 모델·측정 구조의 재현입니다. 나머지는 직접 설계한 **보충 실습**입니다. 교재의 모든 수치 사례·증명·연습문제 해답을 재현한 자료는 아닙니다.
- 기본 비교는 측정 `y(0), …, y(T−1)`로 상태 `x(T)`를 추정하는 **예측형 추정**입니다. 필터링은 현재 측정까지, 평활화는 미래 측정까지 사용합니다.
- 선형·무제약·가우스 조건에서 FIE, 칼만 예측, 정확한 도착 비용의 MHE가 일치하는지 확인합니다. 도착 비용에는 창 이전의 측정만 반영합니다.
- 사전 가중치가 없는 실습은 과정 외란이 없는 모델의 관측가능성 행렬을 분석합니다. 관측가능성과 검출가능성을 구분합니다.
- 비음수 상태 제약 실습은 실제 상태가 양수인 보충 데이터를 사용합니다. 제약 MHE의 도착 비용은 무제약 칼만 사전으로 근사하므로 정확한 제약 FIE와의 동등성을 주장하지 않습니다.
- RTS 평활화는 FIE 전체 상태 경로와 비교하는 보충 예입니다. 교재의 MHE 평활화 사전 갱신식을 그대로 구현한 예는 아닙니다. 측정을 사전과 구간 비용에 중복 반영하면 정보가 과장됩니다.
- 유계 잡음 실습은 스칼라 집합 추정으로, 모델·잡음 범위·초기 집합 가정 아래 실제 상태의 포함 여부를 확인합니다. 일반 MHE 안정성 정리의 수치 증명은 아닙니다.
- 입자 필터는 양·음 상태를 구분하지 못하는 제곱 측정의 다봉 사후 분포를 다룹니다. 평균 하나가 그 분포를 충분히 설명하지 못하는 예입니다.
- EKF·UKF·MHE는 같은 데이터와 예측 시점에서 비교합니다. 비선형 MHE는 EKF 기반 근사 도착 비용과 국소 최소제곱 해를 사용합니다. 한 실험의 RMSE 순위가 추정기의 일반적인 우열을 뜻하지 않습니다.
- MHE+MPC 결합 실습은 별도로 **현재 측정을 포함한 필터링**을 사용합니다. 이미 적용한 입력을 추정 모델에 넣고 입력 한계를 검사합니다. 상태 강제약이나 일반적인 폐루프 안정성을 보장하는 실습은 아닙니다.

## 원본 대조와 이번 보강 내용

- **§4.2 불확실성 검증 보충:** 같은 12,000개 독립 가우스 경로에서 정확한 센서 분산과 R/9를 사용하는 KF를 비교합니다. 마지막 한 시점의 NIS·NEES·RMSE·95% 구간 포함률을 실제 오차 분산 재귀와 검산하며, 시간 상관 표본을 독립으로 세지 않습니다.
- **§4.2, pp.269–278:** i-IOSS의 오차 경계와 정보 시점을 확장했습니다. 현재 측정 하나만 바꾸어 예측에는 아직 반영되지 않고 필터링에는 바로 반영됨을 검증합니다.
- **§4.2.2–4.3.1, pp.281–287:** 같은 출력이지만 서로 다른 숨은 상태를 가진 두 궤적을 비교합니다. 안정한 숨은 모드의 검출가능성과 유일한 초기상태 복원을 구분합니다.
- **§4.3.2, pp.287–294:** 과거 상태를 최소화해 제거하는 Schur 보완과 칼만 사전의 도착 비용 곡선을 직접 대조합니다. 상태 81점에서 일치하며 창 길이 실습과 연결합니다.
- **§4.3.3, pp.294–295:** 상관된 공분산에서 단순 clipping과 제약 최빈값(MAP)의 차이를 비용 타원으로 보여줍니다. 제약 최적점을 절단 분포의 평균이라고 부르지 않습니다.
- **Example 4.40, pp.306–308:** 원본 식 (4.55)–(4.56)에 보충 스칼라 계수 A=1.1, C=G=1, L=0.6, c=1, λ=0.6을 대입합니다. 원본의 1/2 비용 계수를 분석 상수에 유지합니다. 수축 목표 δ=0.2에서 충분 구간 길이는 6, 사전 가중치 상한은 약 3.47e-5입니다. 필요조건이나 최적 구간 길이를 찾은 실험은 아닙니다.
- **§4.5.3, pp.310–312:** 3차 측정 함수에서 UKF 평균이 정확해도 분산은 틀릴 수 있음을 6차까지의 정확한 가우스 모멘트와 비교합니다.
- **Example 4.41, pp.313–314:** 원본 가역 반응, 속도 상수, 실제 초기농도 (0.5,0.05,0), 잘못된 사전 평균 (1,0,4), 샘플 간격 0.25와 압력 계수 32.84를 사용합니다. 명목 농도·압력, 보존량 `3cA+cB+2cC`, 초기상태 식별을 확인합니다. 무잡음 명목 모델의 구조를 재현한 것이며 원본의 잡음 실현·필터별 비교 그림 전체를 재현하지 않습니다. 초기상태 식별은 MHE 전체 구현과 구분합니다.
- **원본 p.314 단위 표기:** 압력식 `p=RTc`에서 RT의 차원은 L·atm/mol입니다. 인쇄된 mol·atm/L와의 불일치를 노트북에 명시했습니다.
- **§4.6, pp.318–325:** 포화 전 명령을 실제 입력 이력으로 착각하면 생기는 예측 오차를 추가했습니다. MPC 결합 실습에서는 실제 적용 입력을 저장합니다.

## 코드 품질과 검증 범위

- 선형 FIE·MHE의 공분산 가중 비용을 Cholesky 백색화와 최소제곱으로 계산합니다. 반복 항마다 역공분산을 만들지 않습니다. 상관된 공분산에서도 칼만 결과와 대조합니다.
- 구간 추정 함수에서 공분산 대칭성·양의 정부호성, 모델 차원, 측정 배열, 사전 정보, 실제 입력 이력 길이를 검사합니다.
- QP의 최적 상태·유한 목적값·제약 잔차를 검사합니다. 비선형 필터의 종류 오타, 음의 분산, 유한하지 않은 데이터도 명확한 오류로 처리합니다.
- 코드를 일관된 형식으로 정리하고 각 실습의 모델과 데이터 생성을 함수 안에 유지합니다.
- 반응기는 DOP853·RK45 적분 결과와 반응식 보존량을 대조합니다. 무잡음 압력으로 초기상태를 식별하는 최소제곱은 국소해이며 일반적인 전역 식별 가능성을 주장하지 않습니다.

`--write`를 빼면 파일을 바꾸지 않고 실행만 검증합니다. 기본 글꼴 측정 경로는 WSL의 `/mnt/c/Windows/Fonts/malgun.ttf`, `malgunbd.ttf`이며, 다른 환경에서는 `MPC_SLIDE_FONT`, `MPC_SLIDE_FONT_BOLD`에 한글 글꼴 파일 경로를 지정합니다. PowerPoint 표시 글꼴은 맑은 고딕·Cambria Math입니다.

Windows PowerPoint에서 PDF를 내보냅니다:

```powershell
powershell -ExecutionPolicy Bypass -File tools/export_pdf.ps1 -Pptx chapter04_state_estimation/slides/chapter04_slides.pptx
```

**노트북 → 그래프 → PPT → PDF** 순서로 갱신합니다. 노트북 수정만으로 PPT·PDF가 자동 갱신되지는 않습니다. README·PPT·PDF의 Colab 링크는 같은 챕터 노트북을 가리킵니다.

## 노트북 실행

기존 개별 `.sh`와 Python 예제는 챕터별 노트북 하나로 대체했습니다. Colab 버튼으로 열거나 `examples/`의 노트북을 위에서 아래로 실행하세요. `run_all.sh`는 개편한 챕터를 한 번씩 실행하고 결과를 저장합니다.
