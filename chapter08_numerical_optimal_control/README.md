## 실습 모델과 해석

- 원본 예제 **8.1·8.3·8.4·8.5 및 8.9·8.11·8.12의 계산 그래프**를 재현합니다. 나머지는 직접 설계한 보충 실습입니다. 교재의 모든 예제·증명·연습문제 해답을 재현하지 않습니다.
- 적분은 정확한 해 또는 독립 고정밀 해와 비교합니다. DAE는 `ẋ=−x+z, z=x²`인 index-1 보충 문제이며 일반 DAE 솔버 구현이 아닙니다.
- 뉴턴 전체 단계의 순환 예는 시작점 0, 감쇠 예는 시작점 −0.5를 사용합니다. 초기값 차이를 명시하며 감쇠의 보편적 성공을 주장하지 않습니다.
- 도함수는 작은 계산 그래프의 전진·역방향 누적, 해석식, 음함수 감도, CasADi 결과를 대조합니다. 차분 근사와 실제 계산 그래프의 미분을 구분합니다.
- **직접 최적 제어:** `ẋ=−x+0.2x³+u`, 초기 상태 0.8, 시간 구간 2, 기본 N=20, 입력 ±1, 상태 ±1.2. 비용은 `∫(x²+0.2u²)/2 dt+x(T)²`입니다. 단일·다중 사격은 같은 RK4 전이·구적을 사용합니다. 중점 배치는 다른 이산 문제이므로 N=10,20,40의 세분화로 차이를 비교합니다. 구간 내부 제약 검사는 유한 표본 검사입니다.
- **SQP·장벽:** 원판 위 거리 최소화의 해석적 해와 비교합니다. SQP는 양의 정부호 헤시안 근사와 L1 메리트 탐색을 씁니다. 장벽 예제는 기본 로그 장벽 뉴턴이며 완전한 원시·쌍대 내부점 솔버는 아닙니다.
- **LQ:** 2상태·1입력, N=18, Q=I, R=0.2, 이산 리카티 종단 비용으로 리카티·축약·전체 KKT 해를 비교합니다. 추가 입력 제한 0.4는 별도 QP로 검사합니다.
- **iLQR·온라인 반복:** 별도 이산 모델 `x⁺=0.85x+0.08x³+0.3u`, N=12, 비용 `Σ(x²+0.2u²)/2+x_N²`입니다. iLQR는 동역학 이차 미분을 생략한 Gauss–Newton DDP이며 강제약이 없습니다. 온라인 비교에서는 입력 한계 1.2를 추가합니다.
- **실시간 반복:** 순차 Gauss–Newton 방식으로 측정당 QP 하나를 풀고 비선형 상태를 재모사합니다. 상태 강제약은 없습니다. 동시 다중 사격 RTI의 중간 동역학 결함을 재현하지 않습니다. 정확히 수렴시킨 비용과 남은 차이를 기록하며, 임의의 NMPC에 대한 안정성이나 실제 장치의 마감시간을 보장하지 않습니다.
