## 실습의 가정과 해석

- 실행 예제는 직접 설계한 **보충 실습**입니다. 교재의 모든 수치 예제·증명·연습문제 해답을 재현한 자료는 아닙니다.
- 추정은 예측형입니다. 현재 입력을 과거 측정으로 계산하고, 현재 측정으로 다음 상태 추정을 갱신합니다.
- 실제 상태 `x`, 추정 상태 `x̂`, 명목 상태 `z`를 구분합니다. 추정 오차 `ε=x−x̂`, 추종 오차 `e=x̂−z`이므로 `x=z+e+ε`입니다.
- §5.3의 강인 실습은 `a=1.1, b=0.5, c=1, L=0.7, K=−1`, `|w|≤0.02, |η|≤0.03`, `|x|≤2, |u|≤0.8`을 사용합니다. 초기 오차가 설계 집합 안에 있고 축소 제약이 비어 있지 않음을 확인합니다.
- 추정 오차 구간은 꼭짓점 전수 검사로, 추종 오차 구간은 스칼라 반경 부등식으로 불변성을 확인합니다. 표본 경로만으로 강인성을 주장하지 않습니다.
- 출력 MPC는 명목 중심을 따로 전파하며 예측 구간 10, 이차 비용, DARE 종단 비용과 불변 종단 구간을 사용합니다. 명목 비용 감소, 실제 상태·입력 제약, 두 오차의 경계를 검사합니다.
- 결합 오차의 방향별 경계는 두 오차가 공유하는 잡음의 관계를 보존합니다. 영 초기 오차의 도달 집합 극한에 대한 계산이며, 이를 다른 초기 상태에 적용하려면 결합 불변 집합 소속을 확인해야 합니다. 앞선 MPC의 제약을 이 값으로 바꾸지는 않습니다.
- 무한 급수는 80항과 해석적인 꼬리 상한으로 계산합니다. 유한 절단값만을 안전한 상한으로 취급하지 않습니다.
- §5.4는 초기 정보에 따른 시변 반경을 전파하는 실습이며, 시변 튜브 MPC 전체 구현은 아닙니다.
- §5.5는 **관측기 기반 명목 MPC**로 외란 추정과 목표 보정의 원리를 확인합니다. 교재 알고리즘 5.7의 강인 오프셋 제어 전체 구현이 아니며, §5.3의 강인 보장을 이 실습에 적용하지 않습니다.
- 상수 외란 실습은 잡음 없는 `a=0.8, b=0.5, d=0.12`, 설정값 1을 사용합니다. 변동 외란에서는 잔여 추적 오차가 남으며, 달성 불가능한 목표는 별도 입력 한계 검사로 구분합니다.
- §5.6은 평균값 정리로 비선형 관측 오차의 전역 경계를 얻는 보충 예입니다. 일반적인 비선형 출력 MPC 안정성·제약 만족을 증명하지 않습니다. 문헌 현황은 원본 2017년 판의 설명으로 읽습니다.

## 편집과 PDF 갱신

`slides/chapter05_slides.pptx`가 편집 원본입니다. 본문·도형·수식 표기는 편집 가능한 PowerPoint 요소이고, 실습 그래프는 이미지입니다.
