## 실습에서 구분하는 보장

- §3.1.2와 Example 3.13은 **원본 모델·계수의 재현**이며, 나머지는 직접 설계한 **보충 실습**입니다. 모든 수치 사례·증명·연습문제 해답을 재현한 자료는 아닙니다.
- 실제 상태 `x`, 명목 상태 `z`, 명목 입력 `v`, 오차 `e=x−z`, 실제 입력 `u=v+Ke`를 사용합니다.
- 선형 강인 실습의 외란은 `|w|≤0.1`입니다. `a=1.1`, `K=-0.6`에서 오차 반경 `s=0.2`의 불변성을 해석적으로 확인합니다. 무작위 경로만으로 강인성을 주장하지 않습니다.
- 작은 최소–최대 예제는 정수 상태와 유한 입력·외란을 가진 별도 문제의 정확한 해입니다. 연속 상태 공간의 격자 근사가 아닙니다. 유한 구간 비용 비교에 폐루프 안정성 주장을 덧붙이지 않습니다.
- 비선형 보조 MPC는 SLSQP 국소해를 수치 검증합니다. 별도의 상쇄 피드백에는 해석적 오차 경계를 보이며, 이 증명을 보조 MPC의 보장으로 옮겨 쓰지 않습니다.
- 가우스 예제는 개별·구간 확률과 분산 수렴의 설명용입니다. 유계 외란에 대한 입력 강제약 보장을 가우스 예제에 적용하지 않습니다.
- 확률적 튜브 제어는 **유계 균등 외란**, 오프라인 표본 상태 여유, 강인 입력 여유를 사용합니다. 초기 시점의 명목 계획을 적용한 뒤 명목 상태·입력을 0으로 연장합니다. 실제 상태로 중심을 매번 재설정하지 않습니다.
- `ε`는 외란 경로의 허용 위반 확률 목표, `β`는 표본 설계가 그 목표를 놓칠 확률의 상한입니다. 독립 검증 빈도의 신뢰한계는 또 다른 통계입니다.
- 표본 설계는 12단계 최대 절대 오차를 하나의 표본으로 취급합니다. 단일 최대값 문제의 정확한 순서통계량 경계 `(1−ε)^M≤β`와 교재의 충분 표본 수 식을 확인합니다.

## 원본 대조와 이번 보강 내용

- **§3.1.2, pp.195–199 / Figure 3.1:** 적분기, 초기상태 1, 길이 3, 명목 최적 입력·시변 이득과 세 외란 경로를 재현합니다. 꼭짓점 8개도 대조하며 종단 폭 6과 3.4, 무외란 비용 21/26을 확인합니다. 이 명목 이득을 최소–최대 최적 정책이라고 부르지 않습니다.
- **원본 p.195 전개식 불일치:** 네 상태 제곱과 세 입력 제곱에 1/2를 곱한 원래 비용을 전개하면 상수항은 `2x²`입니다. 인쇄된 `3x²/2`와의 차이를 명시하고 원래 비용합으로 검증합니다. 이 상수항은 최적 입력에 영향을 주지 않습니다.
- **Example 3.13, pp.231–233 / Figures 3.4–3.5:** 원본 2차원 모델과 K=(-0.4,-1.2), 상자 외란을 사용합니다. 지지 함수·외란 꼭짓점으로 α와 상태·입력 여유를 계산하고, 수축 조건은 근사 길이 3부터, 축소 집합의 존재는 4부터임을 재현합니다. 근사 길이는 온라인 MPC 예측 길이와 구분합니다.
- **§3.2–3.3 보충:** 지속 외란의 잔여 반경을 유도하고, `min max`와 `max min`을 바꾸면 미래 정보를 쓰게 되는 반례를 추가합니다.
- **§3.5 보충:** 작은 튜브와 입력 여유의 관계, 모델 오차를 외란 집합에서 누락하면 생기는 한 단계 위반을 비교합니다. 조건부 반경 계산과 완성된 MPC 재설계의 보장을 구분합니다.
- **§3.7 선택 편향 보충:** 독립 표본 설계 20개 중 최소 여유를 고르면 단일 설계의 β가 유지되지 않음을 정확한 순서통계량과 50,000회 반복으로 확인합니다. 후보별 β/20 배분으로 표본 수를 90에서 149로 늘리는 보정과 최종 독립 검증의 역할을 구분합니다.
- **§3.7 보충:** 단일 최대값 설계의 정확한 표본 수, 무위반 검증의 신뢰상한, 같은 범위라도 분포가 달라질 때 확률적 오차 여유가 깨지는 사례를 추가합니다. 원본 Example 3.23의 500회 반복 표본 실험을 그대로 재현한 것은 아닙니다.

## 코드 품질과 검증 범위

기존 개별 `.sh`와 Python 예제는 챕터별 노트북 하나로 대체했습니다. Colab 버튼으로 열거나 `examples/`의 노트북을 위에서 아래로 실행하세요. `run_all.sh`는 개편한 챕터를 한 번씩 실행하고 결과를 저장합니다.

## 이번 보강판 슬라이드 검증

PPT·PDF 63쪽을 재생성했습니다. 전체 쪽을 렌더링해 개요로 확인하고, 변경된 본문·그래프 쪽은 확대해 검토했습니다. PDF는 LibreOffice에서 나눔고딕·DejaVu Math 대체 글꼴로 내보냈으며, Microsoft PowerPoint 자체에서의 표시 검증은 별도입니다.
